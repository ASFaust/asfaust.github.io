Paths That Never Cross

I wanted a way to procedurally generate linear levels: one long, winding route through terrain, the path a run follows from start to finish. It should look random and organic, it should never stall, and above all it should never cross itself. A linear level that runs into itself is no longer linear.

Random walks with collision checks are the obvious idea, and they are bad at this: they trap themselves in corners and need backtracking. So instead I let a differential equation draw the path. Pick a vector field v on the plane, start somewhere, and follow it:

x′(t) = v(x(t))

What makes this promising is the Picard–Lindelöf theorem. If v is Lipschitz continuous, exactly one solution passes through every point. Two trajectories can never cross, since at the crossing the field would have to point in two directions at once, and they can never merge either. A single trajectory that came back to a point it had already visited would have to repeat itself exactly from there on, as a closed loop. So a smooth vector field gives you paths that never cross. Perlin noise is the standard source of smooth randomness, and the plan seems to write itself.

Two noises, one per component

The obvious way to build a random vector field from noise is one noise per component, v = (P1(x), P2(x)). Below are the arrows of such a field and a dozen paths integrated through it. Click anywhere to start another.

Nothing crosses, so Picard–Lindelöf holds. But the paths die. Each component is zero along some curve, the two zero curves intersect at isolated points, and at every one of those the whole field vanishes. There are lots of them, marked in the figure. Near each zero the field looks like a linear map, which makes it a sink, a source, a saddle or a whirl. A path that wanders into a sink's basin slows down and stops, and one near a whirl spirals in. You get short stubs crawling to a halt, not a level.

The tempting fix is to normalize, using v/|v| so the path always moves at unit speed. Tick the box above. The paths no longer slow down, but the zeros have not gone anywhere. The normalized field is undefined at them, and near them its direction changes arbitrarily fast. It is not Lipschitz there, not even continuous, so the hypothesis of Picard–Lindelöf fails exactly at the points that mattered. A path now reaches a sink in finite time and has nowhere to go: the integrator overshoots, turns around, overshoots again and scribbles over itself. The red rings mark self-crossings. Normalization changes the lengths of the arrows. It cannot change where they vanish, because that is a matter of topology, not speed.

One noise, as an angle

Now use a single noise and read it as a direction:

θ(x) = 2π · 4 · P(x),    v = (cos θ, sin θ)

The factor of four matters. Perlin noise is not uniformly distributed: its values pile up around zero, so a plain 2π·P favors one direction and every path drifts that way. Multiplying by four makes θ sweep the circle several times, and wrapping it through cos and sin spreads the directions out almost evenly while keeping everything continuous. It also makes the angle change four times faster, so the noise lattice here is about three times wider to keep the curves gentle.

Every arrow has length one, and v is a composition of smooth functions, so it is Lipschitz everywhere. There are no zeros, and so no sinks, no sources, no saddles and no whirls.

The reason is topological. Walk once around any closed loop and watch the direction of the arrows. In the component field the arrow can rotate by a full turn along the way, and whenever it does, there must be a zero inside the loop: sinks, sources and whirls turn it by +1, saddles by −1. In the angle field the direction is θ, a single continuous function, so when you get back to the start it is back at the value it started with. The winding number is zero around every loop, for free.

The same argument rules out closed orbits. A path that closed into a loop would turn its own tangent by one full revolution, which requires a zero inside. No zeros, no loops. So a path cannot cross itself and cannot return, and by Poincaré–Bendixson it cannot stay in any bounded region either. Every path eventually leaves. Its turning is limited too: the tangent direction along the path is just θ(x(t)), so its total turning is bounded by the range of θ. It can make U-turns and the odd curl, but it can never wind itself up.

Here is a single path, followed by the camera for as long as you keep watching.

It is a strange thing to watch. The line wanders, swerves, sometimes runs right alongside a stretch it drew earlier, and never touches it.

Two caveats from practice. No zeros does not mean divergence-free: streamlines bunch up along attracting rivers, and paths can get arbitrarily close to each other without touching, which matters if several paths should stay visibly apart. And the guarantee belongs to the exact equation. A finite-step integrator only inherits it approximately, so where streamlines converge hard a large step can still cross. The demos use small Runge–Kutta steps and count self-crossings so you can check. Tiled noise breaks the argument too, since on a torus a path can wrap around and close up without enclosing anything.

The parametrization is the design

Both fields are made from the same ingredient, smooth noise, and choosing between them looks like an implementation detail. It is not. (P1, P2) is a random map into the plane, and a random map into the plane hits the origin. (cos θ, sin θ) is a map into the circle that factors through the real line, so it can neither vanish nor wind. The way you parametrize your field decides its topological properties. It seems like a mundane choice, but one works and one does not.
